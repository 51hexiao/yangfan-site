React 的核心思想是 `UI = f(state)`：视图是状态的函数。本文整理了我学习 React 过程中的关键概念。

## 组件化

把页面拆成一个个独立、可复用的组件，每个组件管理自己的状态和渲染逻辑：

```jsx
function Welcome({ name }) {
  return <h1>你好，{name}</h1>;
}
```

## 声明式

你只需要描述"界面应该是什么样"，React 会帮你高效地更新 DOM。
