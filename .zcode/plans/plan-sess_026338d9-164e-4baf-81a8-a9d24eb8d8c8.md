# 探索模块「高级化」升级计划

目标：把探索模块从「功能齐全」升级为「旅程纪念册」——手账车票视觉 + 地图双向联动 + 灯箱/时间线叙事，延续全站编辑日志风（奶油色、虚线、编号、纸张隐喻），全部只用现有设计令牌，不引入新依赖。

## 前置：恢复示例数据
把 `explore/.trash/` 里 4 篇记录（河坊街/雷峰塔/楼外楼/西湖断桥，均有杭州坐标）移回 `explore/`，去掉文件名时间戳前缀，用于开发与验收。

## 一、数据层 `src/utils/explore.js`（新增纯函数，不动现有导出）
- `cityOf(place)`：从「杭州 · 河坊街」取「·」前第一段为城市
- `totalKm`：haversine 公式累加 trail 中相邻有坐标站点的直线距离（约 15 行，不依赖 AMap）
- `photoCount`：全部记录图片总数
- `gapDays(prev, next)`：相邻两站的间隔天数（旅程叙事用）
- 年份分组数据已导出（`years`），直接用

## 二、列表页「统计条 + 车票卡片」（Explore.jsx / Explore.css）
1. **统计条**：页头副标题升级为「N 站 · N 座城市 · 约 N km · N 张照片」，数字用 rAF 滚动动画（`prefers-reduced-motion` 下直接显示终值）
2. **卡片改「车票/票根」风**：左侧竖排票根区（NO. 编号 + 类型小章）+ 右侧票面（标题/摘要/九宫格/地点日期）；票根与票面间虚线撕边 + 上下缺口圆（radial-gradient）；日期改成右上角微旋转的「邮戳圆章」；保留现有 hover ↔ 地图 pin 联动与 is-active 态
3. **旅程叙事**：相邻两站间隔 ≥1 天时，卡片之间插入「— 间隔 N 天 —」手账虚线贴纸
4. **年份分组**：记录流内按年份分节（年份 >1 时才显示小节标签，当前单年份不产生噪音）
5. 卡片 stagger 入场动画（复用 about-rise 模式，包在 `prefers-reduced-motion: no-preference` 内）

## 三、地图联动升级（TrailMap.jsx）
1. **卡片 hover → 地图平滑飞行**：activeSlug 变化时 `map.panTo()` 平移到对应站点（已在大图视野内则不动，避免晃动）
2. **pin 点击 → 滚动定位卡片**：onSelect 后列表页把对应卡片 `scrollIntoView({ block: "center" })` 并短暂高亮
3. **地图里程角标**：地图左上角加手账「里程牌」小卡（共 N 站 · 约 N km），样式贴主题令牌
4. **航线航行动画（低风险可砍）**：复用「扬帆」意象，加 `AMap.MoveAnimation` 插件，一枚小帆船标记沿虚线航线匀速航行；插件缺失或 `prefers-reduced-motion` 时自动禁用

## 四、图片灯箱（新组件 `src/components/Lightbox.jsx`）
- 全站可复用：props `{ images, index, onClose }`，fixed 遮罩 + 大图 + 「N / M」计数
- 键盘 ←/→ 切换、Esc 关闭、点遮罩关闭；打开时锁 body 滚动
- 接入两处：列表卡片九宫格（点击图不跳详情，stopPropagation）+ 详情页九宫格
- 复用现有 z-index 层级约定与暗色适配

## 五、详情页「明信片」化（ExplorePost.jsx / Explore.css）
1. 有封面时头部改明信片：大封面图 + 右上角邮戳圆章（日期 + NO.NN）
2. 前后翻页 pager 加「间隔 N 天」旅程信息
3. 九宫格接灯箱
